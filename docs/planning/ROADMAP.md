## 📅 마일스톤 상세

### 마일스톤 1: 프론트엔드 마이크로 디테일 (Phase 1)
> **목표**: 상용 앱 수준의 매끄러운 UX 달성
- [x] **멀티 미디어 슬라이더**: 포스트 당 다중 이미지 전환 기능.
- [x] **다국어 자동 감지 및 번역**: i18n 기반 한국어/영어 UI 완성.
- [ ] **Skeleton UI 적용**: 피드 및 프로필 로딩 시 스켈레톤 애니메이션 추가.
- [ ] **낙관적 업데이트**: 좋아요 및 팔로우 인터랙션에 즉각적 반응 적용.

### 마일스톤 2: Spring Boot 백엔드 및 DB 통합 (Phase 2)
> **목표**: Mock 데이터에서 실제 Spring Boot API 기반 서비스로 전환
- [ ] **데이터베이스 구축**: PostgreSQL 또는 MySQL 로컬/클라우드 설정.
- [ ] **JPA 엔티티 모델링**: `ERD_SPEC.md` 기반의 Hibernate Entity 정의.
- [ ] **Cloudinary 미디어 서버 연동**: 이미지/비디오 업로드 및 자동 최적화(썸네일 등) 구현.
- [ ] **RESTful API 구현**: Spring Boot 기반 게시물 작성(미디어 업로드 포함), 좋아요, 댓글 CRUD API 완성.

### 마일스톤 3: 검색 엔진 및 성능 최적화 (Phase 3)
> **목표**: 대규모 데이터 환경에서도 빠른 속도 유지
- [ ] **Spring Data JPA Query**: 데이터베이스 검색 인덱싱 및 성능 최적화.
- [ ] **무한 스크롤(Pagination)**: Spring Data Pageable 기반 페이징 도입.
- [ ] **캐싱 전략**: Redis를 통한 API 응답 가속화.

### 마일스톤 4: 보안 및 서비스 안정화 (Phase 4)
> **목표**: 안정적인 운영 환경 구축 및 배포
- [ ] **인증 시스템**: Spring Security와 JWT를 활용한 로그인 및 세션 관리.
- [ ] **권한 제어 미들웨어**: 팔로우 상태에 따른 접근 권한 제어 엔진 완성.
- [ ] **스토리지 스케일업**: 필요 시 AWS S3 전환 연동 및 대규모 트래픽 대비.
- [ ] **Vercel & 클라우드 배포**: 프론트엔드(Vercel)와 백엔드(AWS/Railway 등) 연결 및 배포.
