# docs/guides/03-optimistic-updates.md - 낙관적 업데이트(Optimistic Updates) 가이드

서버 응답을 기다리지 않고 UI를 즉시 업데이트하여 '무지연' 사용자 경험을 제공하는 전략입니다.

## 🚀 개념
사용자가 '좋아요'를 누르면, 서버의 성공 응답을 받기 전에 클라이언트 상태를 먼저 성공으로 변경합니다. 만약 서버 요청이 실패하면 이전 상태로 롤백합니다.

## 📋 구현 알고리즘
1. **현재 상태 백업**: 에러 발생 시 복구할 데이터를 변수에 저장.
2. **UI 즉시 변경**: `setLiked(true)` 등을 호출하여 화면을 먼저 바꿈.
3. **API 요청**: 서버에 실제 데이터 변경 요청을 보냄.
4. **결과 처리**:
   - **성공**: 그대로 유지.
   - **실패**: 백업해둔 데이터를 사용하여 UI를 이전 상태로 되돌리고 사용자에게 알림(Toast).

## 💡 적용 대상
- 좋아요/좋아요 취소
- 팔로우/언팔로우
- 북마크 저장
- 간단한 댓글 달기
